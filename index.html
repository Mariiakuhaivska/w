Лабораторна робота №2

Створення власної інтернет-сторінки

1. Основні поняття

  • Домен: Унікальна текстова адреса вебсайту в мережі Інтернет (наприклад, example.com), яка використовується для швидкого пошуку та ідентифікації ресурсу.
  • Піддомен (Субдомен): Частина основного доменного імені вищого рівня (наприклад, blog.example.com), яка використовується для створення окремих розділів сайту.
  • Хостинг: Послуга з надання дискового простору та обчислювальних ресурсів на сервері для збереження файлів сайту та забезпечення їх цілодобової доступності.
  • Сервер: Спеціалізований комп'ютер, який володіє високою обчислювальною потужністю, працює безперервно та виконує запити клієнтських пристроїв у мережі.
  • Вебсервер: Програмне забезпечення, встановлене на сервері, яке приймає HTTP/HTTPS-запити від браузерів і надсилає у відповідь вебсторінки.
  • Вебсторінка: Окремий інформаційний документ у мережі Інтернет (на базі HTML, CSS, JS), який має свою унікальну URL-адресу.
  • CMS (Система керування вмістом): Програмна платформа для зручного створення, редагування та публікації контенту на вебсайті без необхідності вручну писати код.

2. Сервіси Google для створення вебсторінки

  • Google Sites: Безкоштовний візуальний конструктор вебсайтів, що дозволяє швидко створювати сторінки без знань програмування.
  • Google Search Console: Інструмент для вебмайстрів, який дозволяє контролювати індексацію сторінок у пошуковій системі та аналізувати пошукові запити.
  • Google Analytics: Сервіс веб-аналітики для відстеження статистики відвідувачів (джерела трафіку, геолокація, популярні сторінки).
  • Google Drive (Диск): Хмарне сховище для розміщення документів, завантаження медіафайлів, які вбудовуються на вебсторінку.
  • Google Fonts / Icons: Бібліотека безкоштовних веб-шрифтів та графічних іконок для оформлення зовнішнього вигляду сторінки.
  • Google Tag Manager: Сервіс для централізованого управління тегами та маркетинговими скриптами без редагування вихідного коду сайту.
